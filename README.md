# Clip Studio

Open-source инструмент для монтажа коротких роликов из загруженных файлов и видео YouTube. Включает браузерный редактор, очередь обработки, локальный или Docker-запуск, экспорт H.264/HEVC и необязательные ИИ-подсказки для поиска фрагментов.

Проект рассчитан на личное или командное развёртывание. Медиа, проекты, экспорты и API-ключи хранятся локально и не входят в репозиторий.

## Возможности

- Загрузка файлов или импорт с YouTube; предпросмотр и выбор качества.
- Монтаж нескольких фрагментов, кадрирование 9:16, 1:1 и 16:9, титры, шрифты, рамки и субтитры.
- Экспорт SDR H.264 и HDR HEVC (при подходящем исходнике и FFmpeg).
- Локальное хранение проектов, очередь задач и автоматическая очистка медиа.
- Необязательные ИИ-подсказки через Groq, OpenAI или Gemini: ключи задаются только через переменные окружения или интерфейс.

## Быстрый старт

Требуются Python 3.12+, Node.js 22+ и FFmpeg с `libx264`, `libx265`, `drawtext`, `libass` и `zscale`.

```bash
cd clip-studio
python3 -m venv .venv
.venv/bin/pip install -r requirements.lock
cd frontend && npm ci && npm run build && cd ..
cp .env.example .env
bash scripts/start.sh
```

Откройте `http://127.0.0.1:8000`. Для разработки интерфейса используйте `npm run dev` в `clip-studio/frontend`.

Проверки:

```bash
cd clip-studio
.venv/bin/python -m pytest -q
```

## Docker

Скопируйте `.env.example` в `.env`, укажите уникальные учётные данные и при необходимости домен, затем запустите:

```bash
cd clip-studio
docker compose up -d --build
```

Не публикуйте `.env`, каталог `data/`, экспортированные ролики, журналы задач или ключи провайдеров. Импортируйте и распространяйте контент только при наличии необходимых прав.
